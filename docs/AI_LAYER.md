# AI 层边界与离线评测

AI 在这个项目里是**可选的文字解释层**，不是选基器，也不参与评分。基金池、收益、回撤、波动率、相对评分和持仓，全部由确定性 Python 代码计算；AI 只把已经算好的指标改写成一段中文说明。

## 它能做什么

- 用户点「生成辅助说明」时，对**当前选中的一只基金**生成一段简短说明和一段详细说明。
- 有 API Key 时，Key 只随当前请求传递，不写入本地文件、不写日志、不进入报告。
- 无 Key、调用失败或输出越界时，退回本地确定性模板，并明确标注「本地规则回退」。

## 它不能做什么

- 不筛选基金、不改变排序、不计算或改写收益/回撤/波动率/评分。
- 不修改持仓、不生成交易指令、不连接账户、不执行交易。
- 不预测未来走势，不承诺收益。
- 不把「AI 生成」当作数据来源；数据来源仍以每只基金旁边的来源徽标和日期为准。

## 输出校验

模型输出在展示前经过两道确定性校验：

1. **数值一致**：文中引用的近 1 月/3 月/1 年收益率、超额收益率、最大回撤、年化波动率，必须与当前表格一致（容差 0.35 个百分点）。
2. **边界一致**：文中不得出现交易指令或仓位指令，包括「买入、卖出、加仓、减仓、补仓、建仓、清仓、平仓、满仓、空仓、止盈、止损、抄底、逃顶、追涨、杀跌、目标价、挂单、下单、委托、调仓、换仓、做多、做空、杠杆、融资、融券、梭哈」，以及「建议持有 / 配置 / 投入 / 赎回 / 申购」「建议仓位提高到 N%」这类模式。

任一条不通过，整段替换为本地模板，并在界面提示已回退。这样即使模型答得「很像投资顾问」，也不会把交易指令带进产品。

## 评测用例

运行：

```powershell
uv run --locked python -m pytest tests/test_fund_ai_layer.py -q
```

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 本地模板边界 | 固定指标 | 不含交易指令词，数值与表格一致，带免责声明 |
| 全部声明词拦截 | 逐个拼接 28 个交易词，再加持有 / 仓位 / 赎回模式 | 每个用例都整段回退本地模板 |
| 边界语句不误伤 | 「不构成买卖指令，也不提供交易方向」 | 保留，不当作交易指令 |
| 交易指令拦截 | 「建议卖出 30% 仓位」 | 整段回退本地模板 |
| 仓位模式拦截 | 「建议将仓位提高到 80%」 | 整段回退本地模板 |
| 数值不一致拦截 | 把 12.0% 写成 99.0% | 整段回退本地模板 |
| 合规文本保留 | 数值一致的纯解释文本 | 保留原文并追加免责声明 |

这些用例验证的是**边界与回退**，不是模型回答质量，也不代表任何投资收益。真实模型输出仍可能措辞不佳；产品只保证它不会越过上述两条硬边界。

## 为什么保留 AI

没有 AI，这个项目仍然完整：来源、日期、回退状态、不可用指标和报告都由确定性代码生成。保留 AI 只是为了验证一件事——**生成式文本可以在不接管数字权威的前提下，作为一层可替换的说明**。如果模型不可用，产品功能不退化，只是少一段文字。
